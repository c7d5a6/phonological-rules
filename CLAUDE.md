# phonological-rules

- Build and test with Zig 0.17.0 exactly (`.zig-version`): `zig build`, `zig build test`,
  `zig build test-service`. See `README.md` and `Style.md`.
- Issues live in Lific (project PHRUL). Follow `docs/issues.md`: **propose issues in chat and
  wait for confirmation before creating or changing any.** When work is finished, check related
  issues and close the ones that are verifiably done (with evidence); ask if unsure.
- Deploy with `./deploy/deploy.sh` only when the user asks; it ships to the real server.
